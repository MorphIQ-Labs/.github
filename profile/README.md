# MorphIQ Labs

## Research-grade math. Proof-gated Rust. Nanosecond-class hot paths.

MorphIQ Labs is an independent research-to-runtime company. We develop
original research and translate papers, models, and signal-processing methods
into proprietary Rust components without losing the math: auditable,
benchmarked, proof-gated where the boundary can be specified, and built for
systems where correctness and latency both matter.

## The implementation stack

| Layer | What lives here |
| --- | --- |
| [**Ferro Suite**](https://www.morphiqlabs.com/portfolio/ferro-suite) | Reusable infrastructure for matching, signal analysis, pricing and risk, spread construction, market data, and deterministic replay. |
| [**Anvil**](https://www.morphiqlabs.com/portfolio/anvil) | A deterministic platform that composes those primitives into journaled, replayable runtime workflows. |
| [**Applications**](https://www.morphiqlabs.com/portfolio/applications) | RangeAtlas, Spread Foundry, Gamma Foundry, and MeridianScope turn the stack into focused product workflows. |

## What we measure ourselves against

- **Keep the math intact.** Assumptions, tolerances, and edge cases remain
  explicit from research through implementation.
- **Prove what can be specified.** Machine-checked primitive laws sit beside
  reference oracles, property tests, mutation testing, and regression suites.
- **Treat performance as a contract.** Hot paths are benchmarked and
  regression-gated so speed does not outrun correctness or auditability.
